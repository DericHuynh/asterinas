The current focused ledger records 1,595 obligations across 26 modules, including SHA/HMAC/HKDF (117) and fsverity (159). The builder check proves exact canonical tree, root-dependent descriptor and measurement bytes whenever build returns Ok, in addition to the existing layout/read contracts. It does not yet prove successful completion iff admission. These filtered diagnostic results do not replace the strict whole-crate gate. The historical typecheck-18 all-32-module artifact predates the SHA completion and fsverity builder contracts and is marked as not matching current sources.

Casefold-checked-native-02 reruns 1,226,715 Linux-corpus comparisons using the focused-checked casefold library, with no replacement implementation and no mismatches. Cluster-init-native-07 similarly uses the focused-checked ledger for eight modeled scenarios and 13 existing API rejections. Neither native run proves Linux equivalence or real device concurrency.

Sha-completion-native-01 replays the unchanged 616-case independent Python corpus against the current focused-checked SHA/HMAC/HKDF artifact with zero mismatches; checked-sha2-native-01 remains historical evidence. This checks runtime conformance for the recorded corpus without supplying a local hash implementation; it is not a cryptographic security or constant-time proof.

Quota-boundaries-native-01 rejects 12 attempts to forge, clone, extract, redirect or reuse private consuming quota state, while three allowed controls compile. These are Rust privacy/ownership checks against the 68-obligation focused ledger artifact. Together with the previous 17 expansion rejection cases, there are 29 new negatives and 369 expected full-suite cases; the official combined rerun is still pending. This is additional boundary evidence, not a newly established Linux defect.

Quota-wire-checked-native-01 also exercises the actual 89-obligation wire artifact: two native tests and three byte-exact user/group/project file rebuilds pass, with e2fsck accepting all three. The harness supplies no replacement implementation. Whole free-list/source ownership integration remains open.

Those were compiler/frontend portability findings, not SMT-discovered filesystem bugs. The original storage decoder remains available for raw/orphan diagnosis and does not confer live-target authority. Its six native tests and focused inode-payload proof passed.

The equivalent match-based lifecycle implementation then passed its unchanged semantic contracts. Such repairs are not counted as discovered Linux bugs.

All failed diagnostic attempts are preserved under /task/ext4-expansion. Native mechanical-erasure artifacts and compile-only artifacts remain explicitly unverified; neither substitutes for a strict whole-crate proof.
